# nyc_employment_analysis: Recovery and Recent Momentum

Analysis of NYC employment by industry using BLS Current Employment Statistics, January 2019 to August 2026. 

**Key findings**
- NYC employment is 4.7% above August 2019
- Education and Health Services added about 226,000 jobs, more than the city's entire net gain
- Year over year frowth turned negative in late 2025, largely due to a state home care program change

**How to reproduce**
Open the project in RStudio and run nyc_employment.R
All cleaning is done in code from unedited BLS downloads. 

**Tools:**
R(readxl, tidyr, diplyr, lubridate, ggplot2)
